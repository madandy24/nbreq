This directory contains accepted historical trackers, evidence ledgers, and superseded pilot
runbooks. They remain part of the project record but are not current implementation plans.

Current working documents remain one level up:

- [`project_nbreq_followup_plan.html`](../project_nbreq_followup_plan.html) — active post-release
  programme and progress tracker.
- [`nbreq_initial_spec.md`](../nbreq_initial_spec.md) — accumulated product and ownership contract.

The main archived groups are:

- `project_nbreq_plan.html` and `wp*_evidence.md` — accepted WP0–WP11 delivery history for the
  original HTTP product and 0.1.0 release.
- `gds_curl_pilot_*` — completed libcurl pilot, canary evidence, and rollback material.
- `gds_native_p10_06_*` — completed native-GDS activation and rollback evidence.
- `wp11_*` — completed release-readiness, security, automation, and soak records.
- `project_nbreq_dns_recovery_plan.html` — completed 0.1.1 DNS transport-recovery incident and
  patch-release record; its D8 enhancements remain deferred in the active follow-up tracker.
- `project_dpwebrpc_sample.html` — pre-NBReq planning/style reference.

Archiving changes location only. Acceptance decisions and recorded evidence are unchanged.
